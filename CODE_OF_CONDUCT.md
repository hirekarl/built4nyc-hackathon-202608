# Code of Conduct

EZStreet was built at the **Built for NYC: AI Hackathon**, presented by The New York Public Library and Major League Hacking. This project follows the **[MLH Code of Conduct](https://mlh.io/code-of-conduct)**, which applies to this repository, its issues and pull requests, and any space where the project is discussed.

In short: be respectful. Harassment, discrimination, and abusive behavior are not tolerated in any form.

## Reporting

To report a concern about behavior in this repository, contact the project maintainer at [@hirekarl](https://github.com/hirekarl), or open a [private security advisory](https://github.com/hirekarl/ezstreet/security/advisories/new) if you would prefer the report not be public.

For incidents at the event itself, follow MLH's own reporting process at [mlh.io/code-of-conduct](https://mlh.io/code-of-conduct).
